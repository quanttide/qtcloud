# ROADMAP — qtcloud Studio

量潮云工作台是量潮云产品线的客户端载体，承载形态 0.1 的门户与协作目录。协作目录核心代码已迁移至 qtcloud-meta 重新规划，v0.1.0 在重新规划的成果上落地首版，部署为「量潮云工作台」。

## 版本目标

| 目标版本 | 形态 | 就绪条件 |
|:--------:|:----:|----------|
| studio/v0.1.0 | 0.1 门户与协作目录 | 部署上线 cloud.quanttide.com |

发布命令：`qtcloud-devops release publish -v studio/v0.1.0`

## v0.1.0 版本范围

- 门户首页：产品矩阵导航，各云卡片链接到对应子域（delib.cloud、data.cloud 等）
- 协作目录：事件目录、契约管理、流程编排三屏，基于 qtcloud-meta 重新规划的事件契约模型
- 应用标识：量潮云 / 量潮云工作台
- 部署链路：Flutter Web 构建、OSS 静态托管、CDN 泛域名证书，对齐 qtclass 与 qtdata 模式

## 关键路径

- 协作目录模型重构：事件、契约、工作流的元模型在 qtcloud-meta 重新规划，回填 studio
- 招聘政策案例端到端闭环：任务输入、拆解、多模块接力、交付草案、验收，逼出任务拆解、契约校验、验收机制三块能力
- 数据源：本地 assets JSON 起步，预留服务端接口
- 信任机制雏形：假设前置化与考核标注设计，为 0.2 任务工作台铺路

## 就绪条件

- 协作目录部署上线 cloud.quanttide.com
- 门户首页可导航各云
- 招聘政策案例闭环跑通
- CHANGELOG 补 [0.1.0] 条目
